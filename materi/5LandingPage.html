1 Pendahuluan

Pada jobsheet ini, kita akan membuat Landing Page untuk aplikasi sebelum masuk ke halaman login. Landing page berfungsi sebagai halaman depan (homepage) yang memberikan informasi awal tentang aplikasi atau website.

Landing page akan memiliki menu navigasi: Home, Profil, Berita, Materi, Hubungi Kami, dan Login. Menu Materi akan menampilkan daftar file HTML yang tersedia di folder materi/.

🎯 Tujuan Pembelajaran:
  • Memahami konsep Landing Page dalam aplikasi web
  • Mampu membuat Controller untuk mengelola halaman statis
  • Mampu membuat View dengan layout yang konsisten
  • Mampu membuat navigasi menu
  • Mampu menampilkan daftar file dari folder
  • Mampu mengatur routing untuk halaman statis
⚠️ Prasyarat:
  • CodeIgniter 3 sudah terinstall
  • Sudah memahami dasar MVC CodeIgniter
  • Web server (XAMPP/Laragon) berjalan
  • Dasar HTML, CSS, dan PHP

4 Controller Landing

File: application/controllers/Landing.php

Controller ini mengatur semua halaman statis landing page.

PHP 
<?php

class Landing extends CI_Controller {
    
    public function __construct() {
        parent::__construct();
        $this->load->helper('url');
        $this->load->helper('file');
    }
    
    /**
     * Halaman utama (Home)
     * URL: /landing atau /
     */
    public function index() {
        $data['title'] = 'Home';
        $data['active'] = 'home';
        $this->load->view('layout/landing/header', $data);
        $this->load->view('landing/index', $data);
        $this->load->view('layout/landing/footer');
    }
    
    /**
     * Halaman Home
     * URL: /landing/home
     */
    public function home() {
        $data['title'] = 'Home';
        $data['active'] = 'home';
        $this->load->view('layout/landing/header', $data);
        $this->load->view('landing/index', $data);
        $this->load->view('layout/landing/footer');
    }
    
    /**
     * Halaman Profil
     * URL: /landing/profil
     */
    public function profil() {
        $data['title'] = 'Profil';
        $data['active'] = 'profil';
        $this->load->view('layout/landing/header', $data);
        $this->load->view('landing/profil', $data);
        $this->load->view('layout/landing/footer');
    }
    
    /**
     * Halaman Berita
     * URL: /landing/berita
     */
    public function berita() {
        $data['title'] = 'Berita';
        $data['active'] = 'berita';
        $this->load->view('layout/landing/header', $data);
        $this->load->view('landing/berita', $data);
        $this->load->view('layout/landing/footer');
    }
    
    /**
     * Halaman Materi - Menampilkan daftar file HTML di folder materi/
     * URL: /landing/materi
     */
    public function materi() {
        $data['title'] = 'Materi';
        $data['active'] = 'materi';
        
        // Ambil daftar file HTML dari folder materi
        $folder_path = FCPATH . 'materi/';
        $files = array();
        
        if (is_dir($folder_path)) {
            $dir = scandir($folder_path);
            foreach ($dir as $file) {
                if ($file != '.' && $file != '..') {
                    // Ambil hanya file HTML
                    $ext = strtolower(pathinfo($file, PATHINFO_EXTENSION));
                    if ($ext == 'html' || $ext == 'htm') {
                        $files[] = $file;
                    }
                }
            }
        }
        
        $data['files'] = $files;
        $this->load->view('layout/landing/header', $data);
        $this->load->view('landing/materi', $data);
        $this->load->view('layout/landing/footer');
    }
    
    /**
     * Halaman Hubungi Kami
     * URL: /landing/hubungi
     */
    public function hubungi() {
        $data['title'] = 'Hubungi Kami';
        $data['active'] = 'hubungi';
        $this->load->view('layout/landing/header', $data);
        $this->load->view('landing/hubungi', $data);
        $this->load->view('layout/landing/footer');
    }
    
    /**
     * Redirect ke halaman login
     * URL: /landing/login
     */
    public function login() {
        redirect('auth');
    }
}
📌 Penjelasan Controller:
  • index() - Halaman utama (Home)
  • home() - Halaman Home (alternatif)
  • profil() - Halaman Profil
  • berita() - Halaman Berita
  • materi() - Halaman Materi (menampilkan daftar file HTML)
  • hubungi() - Halaman Hubungi Kami
  • login() - Redirect ke halaman login

📌 Penjelasan View Materi:
  • Mengambil daftar file dari folder materi/ di root project
  • Hanya menampilkan file dengan ekstensi .html atau .htm
  • Judul file diambil dari nama file (tanpa ekstensi)
  • Setiap file ditampilkan dalam bentuk card dengan icon HTML

  • Jika folder kosong, tampilkan pesan "Belum Ada Materi"
