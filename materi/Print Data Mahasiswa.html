1 Pendahuluan

  • Mampu mencetak atau menyimpan sebagai PDF

  • CodeIgniter 3 sudah terinstall

4 Controller Mhs

File: application/controllers/Mhs.php

Tambahkan method print_data() pada controller Mhs.

PHP 
/**
 * Print data mahasiswa
 * URL: /mhs/print_data
 */
public function print_data() {
    $keyword = $this->input->get('search');
    
    if (!empty($keyword)) {
        $data['mhs'] = $this->M_mhs->search_mhs($keyword);
        $data['keyword'] = $keyword;
    } else {
        $data['mhs'] = $this->M_mhs->get_all_mhs();
        $data['keyword'] = '';
    }
    
    $data['title'] = 'Print Data Mahasiswa';
    $this->load->view('dashboard/mhs/print', $data);
}
📌 Penjelasan Method print_data():
  • Mengambil semua data mahasiswa atau hasil pencarian
  • Mengirim data ke view print.php
  • Mendukung pencarian (search) seperti di halaman utama
